# Pazarlık OS (Obsidian Vault)

Pazarlık ajanının canlı playbook'u. Motor bu vault'u repo'dan okur; taktik notlarının YAML frontmatter'ı sistem promptuna dinamik girer.

Döngü: **Vaka → Retro (Kütüphaneci agent) → Playbook PR → İnsan onayı → Motor güncellenir**

- `01-Playbooks/` — dikey kuralları + taktik kütüphanesi (frontmatter'lı)
- `02-Cases/` — vaka kayıtları
- `03-Retros/` — vaka sonrası analiz + playbook önerileri
- `04-Karsi-Taraf/` — karşı taraf arketipleri
- `05-Metrikler/` — kazanma oranı, taktik skorları
- `_sablonlar/` — taktik ve retro şablonları
